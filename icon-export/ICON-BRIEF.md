# Icon brief — Daniel's Weather (Gulf storm page)

Goal: a home-screen / Dock app icon for a Gulf of Mexico hurricane tracking page. A tropical cyclone
(the classic two-armed spiral) over a breaking wave with white wash. Dark navy background, warm
yellow-orange cyclone. Must read clearly at 60 px (iPhone home screen) and 192 px (Mac Dock).

## Files
- `icon-source.html` — the current icon as an inline SVG (512 x 512). Open it in a browser to view.
  The two spiral arms are generated by the small `<script>` at the bottom (`arm(offset)` builds a tapered
  ribbon); everything else is plain SVG. Edit this file.
- `current-512.png`, `current-192.png` — what the current source renders to.

## What the owner wants fixed / improved
- The cyclone should look like a hurricane symbol: two identical spiral arms, 180 degrees apart,
  tapering evenly toward a clear central eye. Earlier versions looked "tapered on top, full on the bottom";
  the latest version is symmetric but could be more elegant (smoother taper, better arm spacing).
- Waves: a visible crest that curls, with white wash / foam. The current wave is a first attempt and is
  the part most open to redesign.
- Keep it flat and bold; no fine detail that disappears at 60 px. No text.
- Palette: background #15283a -> #0a1219, cyclone #ffd84a -> #ef7f36, sea #2f7fb4 -> #143550, foam #f2f8ff.
  Rounded-square mask radius 110 (Apple applies its own mask; keep the art inside a ~440 px safe circle).

## Deliverable
An updated `icon-source.html` (same structure: 512 x 512 SVG, no external assets). The owner's pipeline
renders it to PNG at 512 and 192 with a headless browser:

    python - <<'EOF'
    from playwright.sync_api import sync_playwright
    with sync_playwright() as p:
        b=p.chromium.launch(); pg=b.new_page(viewport={"width":512,"height":512})
        pg.goto("file:///ABSOLUTE/PATH/icon-source.html"); pg.wait_for_timeout(500); pg.screenshot(path="icon-512.png")
        pg.set_viewport_size({"width":192,"height":192})
        pg.evaluate("var s=document.getElementById('s'); s.setAttribute('width',192); s.setAttribute('height',192)")
        pg.wait_for_timeout(300); pg.screenshot(path="icon-192.png"); b.close()
    EOF

Any tool that rasterises SVG works too (the only JS is the arm generator; if you replace the arms with
static `<path>` elements the script can be deleted).
